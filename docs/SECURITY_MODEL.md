# セキュリティモデル

更新日: 2026-10-05。対象は送信者を限定したCLI向け初期API。
脆弱性がないことを証明する文書ではない。公開時の実環境検証は別途必要。

## 守る対象と信頼境界

平文と復号キーは信頼したクライアントが管理する。Workerは暗号文と取得IDを扱い、
D1は暗号文・UUID・作成時刻を保存する。Cloudflareは暗号文、リクエスト情報、送信認証
トークンを扱える。暗号文も長さ等の情報を持つデータであり、「無意味なゴミ」ではない。
E2EEの成立にはクライアントの認証付き暗号化と鍵の取り扱いの実装・検証が必要。

| 脅威 | 実装・運用上の対策 | 残る制約 |
| --- | --- | --- |
| 並行取得による重複 | 単一のD1 `DELETE … RETURNING` | 通信断で内容を失う。復元・再挿入は範囲外 |
| 未取得暗号文の長期保管 | GET時の24時間判定と毎時GC | GC失敗時の滞留、バックアップの保持 |
| 匿名投稿によるD1消費 | POSTのBearer認証を本文読み込み・DB操作の前に行う | 共有トークン漏えい、許可した送信者の乱用 |
| 誤設定による公開 | `SERVICE_ENABLED`の初期値false、未設定時も503 | 管理者による変更、反映前の進行中リクエスト |
| IDの推測・漏えい | 暗号学的乱数のUUID v4、no-store、アプリでIDをログに出さない | URLログ・管理者・前段監視の漏えい、ID保有者の先取り |
| キャッシュ・エラーからの漏えい | no-store/nosniff/no-referrer、D1失敗は一般化した500 | 前段のキャッシュ設定・ログは別途検証 |
| 大きな入力・不正入力 | 64 KiBのストリーム上限、UTF-8、UUID形式、SQLパラメータ | 分散リクエスト、遅い送信のランタイム資源消費 |
| デプロイ資格情報の露出 | token-free CI、別Jobの環境Secrets、SHA固定、最小権限 | 管理アカウントや信頼したmain、依存ツールの侵害 |

送信認証の値は固定長64文字hex。比較は自作の文字列比較ではなく`subtle` 2.6.1を使う。
固定長により長さの短絡を避け、内容に依存しない比較を意図する。
これは実行環境全体のタイミング挙動の数学的証明ではない。
依存はBSD-3-Clause、default featuresなし、Lockfile固定。

受信者は送信認証トークンを持たず、UUIDが取得権限になる。
復号キーがなくてもID保有者は内容を消費できる。`GET`を共有リンク、先読み、URL検査、
死活監視へ直接渡さない。HEAD/OPTIONSは消費せず、CORS許可は追加していない。
受信操作の確認画面やPOSTベースの取得プロトコルは今回の範囲外。

## 検証と公開条件

ローカルの実Wasm Worker/D1で、認証拒否・設定不足・停止、同時GET、期限境界、GC、
入力境界とDB書き込み/削除失敗を検証する。拒否されたPOSTはDBへ書かれず、
失敗したDELETEはレコードを保持する。テストは公開済みのダミーデータだけを使う。

本番公開の条件は[運用手順](OPERATIONS.md)のZone、D1、Secrets、WAF、利用量監視、
停止・復旧確認に加え、クライアント暗号文形式の一致とリモートの動作確認。
本番アカウントのログ保持、WAF、通知、リモート同時取得はローカル検証で確認できない。

2026-10-05のローカル検証では、Rust整形・Wasm check・Clippy・Workerリリースビルド、
57件のHTTP回帰検証、設定不足・停止と再開時の既存データ保持、本番構成ガードの3テスト、
Actions構文チェックを通過した。24並行GETは200が1件、404が23件。
Cargo.lockの87依存はcargo-audit 0.22.2で既知脆弱性・警告0件、npm監査も既知脆弱性0件。
これは変更中のローカルチェックアウトに対する結果で、GitHub上のCI実行証拠ではない。

匿名公開、利用者別クォータ、利用者ごとの失効、ブラウザー受信画面、厳密な費用上限は
未実装。必要になった場合は、この初期方式の範囲を広げる前に設計を見直す。

根拠: [subtleの比較仕様](https://docs.rs/subtle/2.6.1/subtle/trait.ConstantTimeEq.html)、
[subtleの実装・ライセンス](https://github.com/dalek-cryptography/subtle)、
[D1のTime Travel](https://developers.cloudflare.com/d1/reference/time-travel/)。
